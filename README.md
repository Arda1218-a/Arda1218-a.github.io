## 🔬 Architectural Highlight: The NVIDIA Build Continuum

Four out of five projects are integrated with **NVIDIA Build (`build.nvidia.com`) NIM APIs**, creating a deliberate **Edge-to-Cloud Continuum**:
- **At the Edge:** Ultra-low latency microcontrollers (ESP32 / FreeRTOS) execute immediate physical tasks (tripping relays in 8.2ms during a gas leak, switching to radio mesh in 85ms during a fiber cut).
- **In the Cloud:** **NVIDIA Build API** endpoints provide high-throughput enterprise reasoning: predicting water membrane degradation, balancing multi-floor parking congestion, and generating campus security incident briefings.
- **The Deliberate Exception:** The **Smart Medication Dispenser** deliberately avoids cloud APIs. In life-critical medical adherence, internet downtime or API latency could be catastrophic. True systems architecture means knowing **when to use cloud AI, and when to enforce a 100% physical hardware lock.**
